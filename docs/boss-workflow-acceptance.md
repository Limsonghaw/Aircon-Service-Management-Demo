## 撤回与运行环境

撤回第①项仅需撤回上述三个前端文件的本项差异，不执行数据库迁移或删除操作。已经通过 API 建立的工作单是独立业务记录，撤回入口不会删除它们，仍可从既有列表／客户详情访问。代码撤回不自动撤销已产生的数据。

没有 commit、push、部署、重启或停止服务，也没有替换运行中站点的发布文件。独立构建仅供本次隔离验收，因此现有运行站点未必显示本项修改。
