## 行为及影响

覆盖报价列表状态菜单、报价详情编辑、发票状态菜单及发票编辑。仅已有单据从其他状态保存为目标状态、且状态接口确认返回相同单据和目标状态后触发。新建单据或不改变状态的编辑不触发。没有新增、重命名状态、数据库迁移或权限变更；客户签回文件不决定付款。

提醒先读取现有客户签回文件。空列表显示「是否上传客户签回的 PDF？」「上传 PDF」「暂不上传」；选择暂不上传只关闭提醒，状态已经保存，之后可通过第③项入口补传。已有文件直接展示历史，不重复问是否上传。列表读取失败保留真实错误及重试入口，不假定没有文件。上传复用原附件 API／离开保护／重试，提醒本身不调用状态接口。提醒打开时状态菜单禁用，原请求仍使用同步操作锁。

前端状态响应增加单据 ID／目标状态检查；异常、不完整响应不得显示确认成功或提醒。页面反馈区域获得焦点并滚动至可见位置，手机宽度可见上传／暂不上传两个选择。撤回本项前端差异不会删除附件或撤回已经保存的单据状态，仍保留第③项独立文件入口。

改动：`useCustomerReturnedReminder.tsx`、`CustomerReturnedDocuments.tsx`、报价列表／详情、发票列表及报价／发票 API 服务。不需要后端重启，本轮没有停止、重启或部署服务。
