# Quote / Invoice 打印

先执行 `supabase/migrations/202610010002_add_invoice_document_items.sql`，再重启后端。
旧发票金额保留；新增明细后数据库按每行四舍五入小计减折扣计算金额。
新转换的 Quote 发票自动复制报价明细。状态更新必须保留 items 与 discount。

报价详情、发票列表和手机发票卡片的“打印 / PDF”按钮打开 A4 预览。
公司抬头依据提供的报价 PDF 和发票图片；实际客户、项目与金额来自系统。
可填写打印日期、Ref / PO、联系人及付款条款或服务人员。
这些附加字段仅用于当前预览，不保存到数据库。签名和盖章留空。
老板签名另见 [签名与 PDF 保存](document-signing.md)：附加字段会随签名快照保存，
已签名 PDF 使用独立下载入口，普通打印仍保持未签名版。
点击“打印 / 保存 PDF”，在浏览器选择打印机或“另存为 PDF”。
打印时选择 A4 并关闭浏览器页眉页脚。超过一页的明细自动分页且重复表头。

验收：分别预览报价、旧发票、带折扣的新发票及从 Quote 转换的发票；
检查客户地址、行小计、折扣后金额、中文抬头、签名栏与多页明细。
在手机宽度检查入口和发票明细编辑，打印后应仅包含单据内容。
