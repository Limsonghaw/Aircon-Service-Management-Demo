# PDF 预览闪烁修复

2026-10-13。用户反馈客户签回 PDF 预览反复显示「正在显示PDF页面…」。

已复现根因：PdfPages 每次重绘前将 canvas display:none，滚动条因此消失，使 ResizeObserver 观察到可用宽度增加；画布重绘并显示后又出现滚动条，宽度减小，进入循环。开启标准滚动条后，旧版 1440px 视口的 PDF 宽度在 926／911px 间来回切换，5 秒观察期间出现 646 次加载相关 DOM 变化。自动化默认隐藏滚动条，最初未复现；测试已显式取消该默认参数。

修复只修改两个位置：画布重绘期间使用 visibility:hidden 保留布局占位；附件预览滚动区域使用 scrollbar-gutter:stable 保留滚动条宽度。保留真实加载、失败和重试提示，未隐藏错误或改变文件请求／权限／数据。

TypeScript、相关 ESLint、独立构建通过。隔离编译前端使用实际 PDF.js 和 QA PDF，浏览器开启普通滚动条，修复后桌面／手机宽度连续观察 5 秒，测量宽度各自稳定为 911／337px；加载状态只有初始 2 次 DOM 变化并结束。主动缩放后再连续观察 3 秒无新增加载变化。5 页 PDF 的下一页、上一页均正常，完成后无持续加载提示，无页面异常。

证据：`.local-deploy/qa-pdf-flicker/` 中 `before-results.json`、`after-results.json`、`check.cjs`、`fixed-1440.png`（缩放后 1100px）、`fixed-390.png`（缩放后 360px）。已实际查看两张截图。测试使用隔离文件 API，不是当前已登录系统或实体手机实测；当前 Vite 开发页面可刷新后验收。

无迁移、依赖、权限或业务流程变化，没有 commit、push、部署、重启服务、删除记录或文件。共用 PDF 阅读器的修复也适用于 PO／收据等已有 PDF 预览。
