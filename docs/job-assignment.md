# 团队工作分配

先执行用户权限 migration，再执行 `supabase/migrations/202610010001_add_employee_job_access.sql`。

老板或管理员在“用户与权限”选择账号对应的员工。一个员工只能绑定一个账号。
在工作单编辑表单选择施工团队；该团队的有效员工通过绑定账号查看同一批工作。
员工登录后的工作单和日历由后端按当前用户 ID 查询，无法通过请求参数查看其他团队。
未绑定、员工停用、团队停用或员工未加入团队时，工作列表为空。
员工仍为只读；老板和管理员保留全部工作及现有编辑功能。

验收：建立两个团队及各自员工，绑定两个员工账号，给各团队安排不同 Job。
分别登录两个账号，核对列表与日历只显示所属团队的工作；解除绑定或停用后刷新验证为空。
修改团队名称后确认现有 Job 与可见范围同步。重复绑定同一员工应显示错误。
